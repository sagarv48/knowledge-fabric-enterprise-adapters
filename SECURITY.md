# Security Policy

## Supported Versions

We release patches and security fixes for the active minor release branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is critical to Enterprise Adapters, especially given its role in handling SaaS credentials, automated secret scrubbing, and cryptographic action authorization gates.

If you believe you have discovered a security vulnerability in Enterprise Adapters:

1. **Do not open a public GitHub issue.**
2. Please submit a confidential report via GitHub Private Vulnerability Reporting or contact the maintainers.
3. Provide a clear description, proof of concept, and reproduction steps.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.

## Security Best Practices & Configuration

| Environment Variable | Default | Purpose & Flexibility |
| :--- | :--- | :--- |
| `ADAPTERS_REDACT_SECRETS` | `true` | When `true`, automatically scrubs Bearer tokens, Basic auth headers, query parameters, and API keys before logging or raising exceptions. |
| `FABRIC_SIGNING_KEY` | *(None)* | Secret HMAC-SHA256 key used to cryptographically verify approval tokens generated by Intent Fabric. |
| `FABRIC_APPROVAL_ENFORCEMENT` | `enforce` | Controls whether action adapters strictly verify approval signatures before executing write mutations (`enforce` vs `permissive`). |
