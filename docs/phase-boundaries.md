# Phase Boundaries

## Phase 1

- Knowledge Fabric
- Retrieval only

## Phase 2

- Intent Fabric
- Planning, approval, simulation only

## Phase 3

- Private enterprise adapters
- Read-only discovery first
- Policy-gated write actions second

## Keep separate

- No retrieval internals in Phase 3
- No runtime execution in Phase 1 or Phase 2
- No public docs for private systems
